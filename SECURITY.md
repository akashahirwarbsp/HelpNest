# Security Policy

## Scope

HelpNest is a demo application. It does not include a backend, authentication, or a production database.

## Reporting a vulnerability

Please do not publish exploit details for a security issue before the maintainer has had a reasonable opportunity to review it. Use the repository's private security advisory feature where available, or contact the maintainer through the contact details listed on the GitHub profile.

## Important limitations

- Local browser storage is not a secure database.
- The sample server is intended for local development and binds to `127.0.0.1` by default.
- Do not store secrets or personal customer information in this demo.
- A production deployment requires a security review, server-side validation, authentication, authorization, and appropriate data protection controls.
