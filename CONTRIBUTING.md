# Contributing to HelpNest

Thanks for considering a contribution! HelpNest is a small, dependency-free demo that aims to stay approachable for new developers.

## Before opening a pull request

1. Open an issue for large features or behavior changes so the scope can be discussed.
2. Keep changes focused and explain the user problem they solve.
3. Never add real customer data, secrets, API tokens, or credentials.
4. Preserve the demo-only notice unless the app's architecture and privacy behavior are genuinely changed.

## Development

- Use Node.js 18 or newer.
- Run `npm run check` and `npm test` before submitting.
- Add tests for new pure utility functions and important edge cases.
- Prefer semantic HTML, keyboard-friendly controls, and responsive CSS.
- Avoid dependencies unless there is a clear benefit.

## Pull requests

Include a short summary, testing details, screenshots for visible UI changes, and any known limitations. Be respectful and follow the Code of Conduct.
